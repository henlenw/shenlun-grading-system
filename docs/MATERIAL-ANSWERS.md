# 材料阅读与图文作答增量交付

本说明描述材料阅读、勾画、文字和图片作答。运行时默认人工批改。


## 学生使用

1. 登录网站，在“我的训练”打开已授权题目。材料与题目要求分别显示。
2. 在材料中长按选择文字，使用浏览器或微信系统复制菜单；也可点“复制所选”。复制仅在浏览器内完成，不调用后端。
3. 选中文字后点“下划线、高亮、删除线、圈选/标记”。标记自动保存；“我的勾画”可查看和移除。每轮最多 100 处，单处最多 10000 字。教师的原下划线独立保留。
4. 点“开始答题”，选择文字、图片或文字 + 图片。新一轮可重新选择方式。
5. 文字立即保留在本机，停止输入 5 秒同步云端，提交前再次同步。重新打开时，若有未同步的本机草稿，页面提供恢复选择。建议字数超限只提醒；沿用系统 30000 字符的长文本安全上限。
6. 图片支持拍照和相册多选，每轮最多 5 张。浏览器先压缩到长边不超过 2048 像素、每张不超过 2 MiB；可调整顺序、删除重选、点开检查字迹。无法解码的 HEIC 照片需转换为 JPG/PNG。压缩不能保证所有原始照片的手写字都清晰，提交前需要检查。
7. 提交时按实际内容保存 text、image 或 mixed。提交后本轮答案与材料标记锁定，仍可复制材料。老师发布后查看成绩、评语及批注，按题目设置解锁参考与评分标准，最多训练三轮。

## 教师使用

题库材料框可选中文字并点“为选中文字加下划线”，展开预览检查显示。材料支持少量文本格式，页面不会执行粘贴内容中的 HTML 脚本或加载任意嵌入资源。

批改页先显示“学生文字答案”，再显示“学生作答图片”。文字可选中后批注；图片保留放大、圈、框、下划线、箭头及文字批注。填写分数和教师反馈后正式发布。无 AI 结果时不显示辅助初批面板。

## 数据与迁移

- `SubmissionAttempt.answerType`：当前草稿选项及提交时的真实方式；新草稿空值表示尚未选择。
- `SubmissionAttempt.text`：继续存原文字答案，学生 API 同时提供 `answer_text`，没有重复存储历史答案。
- `Attachment`：继续保存原私有附件，增加 `position`；学生 API 提供有序的 `answer_images`，保留历史附件兼容。
- `SubmissionAttempt.studentAnnotations`：学生材料勾画，与 Question 材料完全分开。独立 `annotationsVersion` 防止多设备覆盖，同时不干扰文字草稿版本。
- 标记绑定现有 Attempt → Submission → Assignment，包含学生、原作业/试卷上下文、题目和轮次。沿用现有同一学生同一道题跨重复授权共用三轮的规则，不重复创建训练历史。
- 新接口：`PUT /api/student/attempts/:id/material-annotations`（version、annotations）；`PUT /api/student/attempts/:id/files/order`（version、完整 ids 列表）。只能由当前学生修改当前有权限的草稿；提交后冻结。
- SQLite/PG 增量迁移均为 `202610050001_material_answers`。迁移添加字段并回填历史方式和附件顺序，不删除原记录。PG 迁移可重复执行，回填仅在列首次建立时执行，不重置后续排序。
- 对已有数据库进行迁移前，先下载并验证备份，再核对增量迁移不会删除旧字段或记录。

## 验证

自动测试覆盖学生隔离、勾画版本冲突、图文提交、图片排序、三轮发布和历史数据迁移。手机拍照、系统复制菜单和微信浏览器行为需在目标真实设备上验收。
