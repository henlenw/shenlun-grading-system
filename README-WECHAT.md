# 考吧167：微信开发者工具导入

交付目录为 `release/miniprogram`，已编译为原生 JavaScript，包含 app.js、app.json、app.wxss、project.config.json 和 12 个原生页面。不是 WebView。

## 网站上线后，只需填写两项

在项目根目录执行（将下列值换成控制台实际信息；示例不能直接使用）：

```powershell
$env:WECHAT_APPID='你的小程序 AppID'
$env:PUBLIC_API_URL='https://你的真实网站域名/api'
node scripts/build-miniprogram.mjs
```

1. 打开微信开发者工具，选择“导入项目”，目录选择 `release/miniprogram`；AppID 使用本人小程序的 wx 开头 AppID。
2. 后端同一环境填写 WECHAT_APPID、WECHAT_APPSECRET。AppSecret 只放后端，不放小程序代码。
3. 微信公众平台 → 开发管理 → 开发设置，将网站的 **HTTPS 域名（不带 /api 路径）** 加入 request、uploadFile、downloadFile 合法域名。域名必须符合微信平台的校验要求；云托管默认域名是否适用于你的账号，以平台校验为准。
4. 编译 → 真机预览。检查首次登录、上传照片/PDF、作答、批注和三轮训练后，再上传开发版本、提交审核、发布。
5. 隐私保护指引说明照片/文件仅用于学生作答与老师批改，并填写实际运营方联系人。没有 AppID 时只能做本地开发检查，不能冒称真机验收或已发布。

## 共用账号

- 从网页开始：老师添加学生 → 学生用绑定码激活网页账号 → 小程序微信登录 → “已有网页账号，绑定到微信” → 输入同一网页账号密码。
- 从微信开始：老师添加学生 → 微信登录并输入老师绑定码 → 我的 → 网页账号 → 设置账号密码 → 在手机网站登录。
- 两种路径都使用相同 User.id。题目权限、草稿、提交、成绩、原稿和批注不会复制成两套数据。
- 忘记网页密码：老师在学生管理中“重置网页账号”，发新的激活码；历史记录和微信绑定保留。
