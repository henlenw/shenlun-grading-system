# 脱敏范围

- 独立源码副本；从全新的 Git 历史开始，不带原目录运行状态。
- 不包含 .env、云 API Key、会话密钥、初始化密钥、微信密钥或真实管理员密码。
- 不包含数据库、备份、学生原稿、业务导出、日志、页面截图或测试运行目录。
- 不包含现有云环境 ID、云账号 ID、服务 URL、资源/迁移执行回执。
- 不包含本机绝对路径、原始需求附件和聊天提取文本；改为可独立使用的说明。
- 只保留通用环境模板；测试文件中的账号/密码/令牌均为虚构测试数据。
- 保留业务源代码、数据库结构与迁移、测试、产品品牌图片和依赖锁文件。

仓库仅用于私有代码管理。新增提交前检查 git diff --cached；真实配置、凭据和业务数据应继续保存在仓库外。
